# Basic Calculator

This project contains a simple C program for basic arithmetic operations.

## File

- `pr4.c` — performs addition, subtraction, multiplication, and division based on user input

## Run the program

Compile and run it with:

```bash
gcc pr4.c -o pr4.exe
pr4.exe
```

## How it works

The program asks for:

- first number
- second number
- operation choice

Available choices:

- 1 = Addition
- 2 = Subtraction
- 3 = Multiplication
- 4 = Division

Example:

```text
enter the first number: 10
enter the second number: 5
enter 1.Addition, 2.subtraction, 3.multiplication, 4.division
: 1
addition= 15
```

## Notes

- This is a beginner-level C program for learning input handling and `switch` statements.
